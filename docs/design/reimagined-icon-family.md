# Reimagined tooling icon family — proposed baseline

Status: color and silhouette family approved on 2026-09-11. Production PNG/ICO assets are maintained in each application project. Launcher retains its original top-left in-app branding.

## Shared identity

Use one compact badge with a restrained horned upper edge. Keep the silhouette broad and close to square so it occupies the same visual area as neighboring desktop icons. Use a large ivory symbol inside it, with generous negative space.

Suggested production colors: Launcher crimson #E53935, Mod Studio amber #E6A62C, Level Editor teal #168C91, and shared ivory #FFF3DB. Adjust amber darker if needed for clear small-size glyph contrast. The generated concept is visual exploration; production masters should use exact colors and consistent geometry.

## App symbols

| Application | Primary symbol | Badge color |
| --- | --- | --- |
| Reimagined Launcher | Play triangle | Crimson |
| Reimagined D2R Mod Studio | Table: header and four large cells | Amber |
| Reimagined Level Editor | Two stacked terrain layers | Teal |

The silhouette, proportions, padding and symbol weight stay consistent. Badge color and the central symbol both distinguish apps, so they do not rely on color alone. Avoid fine patterns: they become visual noise at taskbar sizes. Future applications should use one similarly simple functional symbol.

## Small-size requirements

- Review actual 16, 24, 32 and 48 pixel exports on dark and light taskbars before accepting an icon.
- Fill roughly 85–90% of the square canvas, leaving room for horn tips and optical alignment.
- No text, texture, metallic bevels, fine outlines, miniature accessories or secondary badges.
- At 16 pixels, simplify the table if necessary; preserve clear separations between cells.
- Use a shared editable vector master for production; export PNG and multi-resolution ICO assets from it.
- Keep launcher/editor packaging, executable resources and window icons consistent when rolling out the approved family.
